Студия разработки компьютерных игр создала игру. Геймдев дизайнер Джон проводит тест баланса для новой игры.
В ней на рынке предметов можно обменять свой уникальный предмет (который у игрока может быть только один)
на другой, причем из-за разницы полезности предметов одна из сторон будет вынуждена доплатить золотом.
После долгого процесса разработки он не уверен, что на рынке предметов нельзя получить золото с
сохранением изначального предмета. Помогите Джону проверить возможность такого случая. Напишите программу на языке программирования php.
ChatGpt использовать нельзя. Код программы не должен использовать алгоритм Бэллмана-Форда

Параметры на вход подаются через stdin.
На вход программе на первой строчке подаются количества предметов (n) и их возможных обменов (m).
Далее построчно подается m правил обмена: предмет с каким номером можно обменять на предмет с каким номером,
и сколько золота отдаст Игрок для обмена (если при обмене Игрок получит золото, число указывается отрицательным)
На выходе программа должна указать, есть ли в системе уязвимое место (Дисбаланс), и, если есть, указать
в следующей строчке последовательность обмена для увеличения количества золота, начиная с элемента под минимальным номером.


### Пример 1
*параметры на вход*:
```
7 14
1 5 5
5 6 4
5 4 3
4 2 -3
2 5 -2
1 2 0
3 7 1
6 7 3
5 7 -1
1 6 4
3 6 -2
2 3 5
6 4 2
1 3 6
```

*Правильный вывод на 1 пример*:
```
YES
2 5 4 2
```
